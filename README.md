# Dr. Javohir — Proctology & Health

Static, mobile-friendly educational website. The site is provided as a starting point for publication.

## Publish with GitHub Pages
1. Visit https://github.com/new
2. Create a **Public** repository named `javohir-proctology`.
3. Upload `index.html` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to finish deploying. The URL will be shown in Settings → Pages.

## Before using with patients
- Verify medical content against current clinical guidance.
- Add only confirmed phone numbers, addresses, and social links.
- The appointment/request form is not connected to a secure backend. Do not collect sensitive patient information through it until a secure system is implemented.
- Confirm that all images and illustrations have appropriate usage rights.
